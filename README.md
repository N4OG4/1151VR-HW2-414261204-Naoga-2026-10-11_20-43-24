# 製作流程和相關操作

當安裝好 unity hub 後，開啟專案

於 github 開啟新 repo 設定為"公開" .gitignore 套用 unity

上網尋找圖案

下載下來導入專案 Assets 目錄，再視窗中拖曳至 Scene

接著新增Component "New Script" 取名放入 Scripts/ ， 寫好程式後，點擊視窗上方的 ▶ 執行專案

確認畫面中有顯示模型後，開啟螢幕錄影再執行一次

最後將影片上傳至 YouTube
